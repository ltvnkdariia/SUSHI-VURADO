## About the Project
Sushi Vurado is a full-featured web platform tailored for the food and beverage industry, providing a seamless user experience for browsing menus, placing orders, and exploring interactive features. 

> **Note on Database Integration:** 
> While this repository features a frontend implementation, I have also developed an exact functional counterpart of this project that is fully integrated with a **real backend database** for live data persistence, user authentication, and order management.

##  Key Features
* **Modern UI/UX:** Built with clean design principles, smooth animations, and a responsive layout.
* **Interactive Menu & Ordering:** Dynamic product exploration and cart management.
* **Full-Stack Capability:** Designed with database scalability in mind (paired with a database-connected version).

## Technologies Used
* HTML5, CSS3, JavaScript (Frontend)
* Modern CSS Frameworks / Tailwind CSS
* Database integration available in the full-stack version (SQL/NoSQL architecture)
